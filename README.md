# Habi Febriansyah — Portfolio

Website portfolio statis berbasis HTML/CSS/JavaScript dan siap dipublikasikan dengan GitHub Pages.

## Publish di GitHub Pages

1. Buka Settings → Pages pada repository.
2. Pada Build and deployment, pilih Source: GitHub Actions.
3. Workflow `.github/workflows/deploy-pages.yml` akan menjalankan deployment otomatis setiap ada push ke branch `main`, atau bisa dijalankan manual dari tab Actions.
4. Setelah workflow berhasil, alamat situs tersedia di Settings → Pages. Untuk repositori ini biasanya berbentuk `https://habifebriansyah98-web.github.io/habifeb/`.

Tombol "Simpan sebagai PDF" pada halaman membuka dialog cetak browser. Pilih Save as PDF untuk menyimpan versi CV/portfolio.
